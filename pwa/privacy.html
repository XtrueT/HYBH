隐私政策

最后更新：2026-10-12
一句话概括：本应用不设账号、不上传你的训练与饮食数据；所有记录只保存在你自己的浏览器里。站点仅使用托管平台自带的、无 Cookie 的匿名访问统计。

1. 我们保存什么、保存在哪里

  • 你在应用内产生的全部数据——身高体重、训练计划、饮食方案、每日打卡记录、自定义动作——都通过浏览器的 localStorage 保存在你自己的设备上，存储键名为 dumbbell_fit_v1。
  • 这些数据不会上传到任何服务器，开发者无法查看、也无法获取。
  • 清除浏览器数据、卸载浏览器，或使用应用内「设置 → 重置数据」，都会永久删除这些数据且无法恢复。建议定期使用「设置 → 导出 JSON」自行备份。

2. 我们不做的事

  • 不要求注册或登录，不收集姓名、手机号、邮箱等身份信息。
  • 不接入广告 SDK，不做用户画像，不进行跨站追踪。
  • 不使用 Cookie 存储你的个人信息；应用仅使用 localStorage 做功能存储。

3. 第三方服务

本应用部署在 Cloudflare Pages 上，因此访问会经过 Cloudflare 的网络：

  • Cloudflare Web Analytics：用于统计站点访问量（页面浏览、来源、大致地区、设备类型等）。该服务不使用 Cookie，不采集个人身份信息，仅提供聚合统计结果。
  • 作为托管与加速服务商，Cloudflare 可能为安全与防滥用目的处理访问 IP 等基础网络信息，具体以其官方隐私政策为准。

4. 你的权利与选择

  • 导出：随时通过「设置 → 导出 JSON」取走全部数据。
  • 删除：通过「设置 → 重置数据」一键清空，或直接清除浏览器站点数据。
  • 拒绝统计：可用浏览器插件或隐私设置拦截 static.cloudflareinsights.com，不影响应用功能。
